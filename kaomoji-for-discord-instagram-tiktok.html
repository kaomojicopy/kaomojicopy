Kaomoji for Discord, Instagram, TikTok and WhatsApp

Kaomoji are plain text, so they work almost everywhere you can type. This guide covers the apps people ask about most, the small problems you may meet, and how to fix them.

Kaomoji on Discord

Kaomoji work in messages, nicknames, and statuses on Discord. The one catch is formatting: Discord reads underscores, asterisks, and backslashes as markdown, which can change a face. The shrug is the classic example, which loses its arm. Type a second backslash, or put the face inside a code block, to keep it whole. See shrug emoticons for more.

Kaomoji on Instagram

You can paste kaomoji into your bio, captions, comments, and messages. Bios have limited space, so short faces work best. Soft, simple styles like cute kaomoji and aesthetic kaomoji are popular for bios. Check that the face looks right after you save, since the display font can differ from your keyboard.

Kaomoji on TikTok

Kaomoji work in TikTok comments, captions, and your bio. Keep them short in places with tight limits. Happy and cute faces, like happy kaomoji, are a quick way to add personality to a comment.

Kaomoji on WhatsApp

WhatsApp uses asterisks and underscores for formatting, so a face that contains them may change. If a face looks wrong, try one without those characters. Greeting and love faces, like greeting kaomoji and love kaomoji, work well in chats.

Kaomoji on X, Telegram, Snapchat and YouTube

All of these accept plain text, so you can paste kaomoji into posts, replies, chats, and comments. Watch for character limits, because some symbols count as more than one character.

Kaomoji in usernames and display names

Many apps allow special characters in display names, but rules differ, and some apps strip or block certain symbols. Test the name first, and avoid using a kaomoji in an account name you cannot easily change.

Kaomoji in email, documents and notes

Kaomoji paste into email, documents, and notes the same way as any text. In formal writing, one face is enough, and many people skip them in work emails.

Troubleshooting checklist

  • A box appears: try another face or update your system fonts.
  • A part of the face is missing: the app may be reading a symbol as formatting, so use a code block or another face.
  • The face looks different: apps use different fonts, so spacing can change a little.
  • The paste fails: copy again, or paste into a plain text field first.

Which kaomoji to try first

Start with cute kaomoji, happy kaomoji, and love kaomoji. For classics, try the shrug, lenny face, and table flip. To learn how the faces are built, read kaomoji symbols.
